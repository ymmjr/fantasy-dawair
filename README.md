# فانتسي دوائر — النسخة السحابية

نظام فانتسي كرة القدم الخاص بفصل **دوائر**، مهيأ للنشر على Railway مع PostgreSQL.

## القواعد الموجودة في النظام

- 4 مجاميع، والاختيار الإجباري: **لاعبان من كل مجموعة**.
- قائمة الفانتسي: **8 لاعبين = 6 أساسيين + 2 احتياط**.
- الكبتن ونائب الكبتن من الأساسيين فقط.
- لا أسعار، ولا مراكز، ولا نقاط كلين شيت.
- الطاقات، وكل طاقة تستخدم مرة واحدة:
  - الكبتن ×3.
  - تفعيل الدكة.
  - تغيير شامل.
- النقاط الافتراضية:
  - الهدف +3.
  - الفوز +5.
  - الهاتريك +3 إضافية.
  - الحضور +3.
  - أفضل لاعب +8.
  - الكرت الأصفر -2.
  - الكرت الأحمر -5.
  - عدم ارتداء الحذاء الرياضي -3.
  - الهدف العكسي -2.

جميع قيم النقاط الأساسية قابلة للتعديل من لوحة المشرف.

## البنية

- `server.py`: الخادم وواجهات API ومنطق الفانتسي.
- `public/`: واجهة الموقع RTL للجوال والكمبيوتر.
- PostgreSQL عند وجود `DATABASE_URL`.
- SQLite تلقائياً للاختبار المحلي فقط عند عدم وجود `DATABASE_URL`.
- `schema_migrations`: أساس لترقيات قاعدة البيانات لاحقاً بدون مسح التشكيلات.
- `/health`: فحص جاهزية للسيرفر وقاعدة البيانات.

## النشر على Railway

1. أنشئ Project جديد في Railway.
2. أضف خدمة PostgreSQL من `+ New` ثم Database ثم PostgreSQL.
3. أضف خدمة للموقع واختر GitHub repository: `fantasy-dawair`.
4. من Variables في خدمة الموقع أضف:
   - `DATABASE_URL=${{Postgres.DATABASE_URL}}`
   - `ADMIN_USERNAME=admin`
   - `ADMIN_PASSWORD=` كلمة مرور قوية خاصة بك.
   - `COOKIE_SECURE=1`
   - `SEED_DEMO=0`
5. Deploy.
6. من Settings > Networking أنشئ Public Domain.
7. افتح الرابط وسجل دخول المشرف، ثم أضف اللاعبين والمشتركين.

> إذا كان اسم خدمة PostgreSQL عندك مختلفاً عن `Postgres`، استخدم الاسم الفعلي للخدمة داخل مرجع المتغير.

## حماية البيانات عند التحديث

الكود وقاعدة البيانات منفصلان. تحديث GitHub وإعادة نشر الموقع لا يمسح PostgreSQL. الجداول تُنشأ بصيغة `IF NOT EXISTS` ويوجد سجل `schema_migrations` لتطوير القاعدة مستقبلاً بطريقة تراكمية.

قبل أي تطوير كبير، استخدم زر **تنزيل نسخة احتياطية** من لوحة المشرف.

## تشغيل محلي للاختبار

بدون `DATABASE_URL` يستخدم النظام SQLite داخل `data/fantasy.db`:

```bash
ADMIN_PASSWORD="StrongPassword123!" SEED_DEMO=1 python server.py
```

ثم افتح:

```text
http://localhost:3000
```

## ملاحظات أمنية

- لا تضع كلمات المرور أو `DATABASE_URL` داخل GitHub.
- ملف `.env` مستثنى من Git بواسطة `.gitignore`.
- إذا لم تحدد `ADMIN_PASSWORD` في قاعدة جديدة، ينشئ النظام كلمة مرور عشوائية ويعرضها مرة واحدة في Log عند التهيئة الأولى.
- غيّر كلمة مرور المشرف بعد أول دخول.
